## 🎯 The Experiment (A/B UI Test)
Can an AI model fully comprehend complex, Apple-tier Design Systems and Micro-interactions without human CSS tweaking? 

This repository contains two parallel iterations built from the exact same root `design_system.md` constraints:

*   **`v1_HTML_Tailwind/`**: The static structural skeleton. Focuses heavily on grid systems, negative space (padding/margin), and semantic HTML layout.
*   **`v2_React_Vite/`**: The interactive "Magic Moment". Built with React and Framer Motion, it injects advanced micro-interactions like Custom Magnetic Cursors and Parallax Glassmorphism.

## 📦 The Prompt (The Core Engine)
The entire aesthetic constraint system (Titanium minimalist vibe, strict spacing ratios, glassmorphism rules) is documented and version-controlled. 
👉 **You can find the raw generation instructions in [design_system.md](./design_system.md).**

## 🚀 Quick Start (Running V2 locally)

To experience the interactive Framer Motion environment:

```bash
cd v2_React_Vite
npm install
npm run dev
```

Visit `http://localhost:5173` to view the live dashboard.
